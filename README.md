# 動画カットツール

ゲーム実況などの長い録画（数GB・数時間）から、必要な区間を抜き出したり、不要な区間を削除したりする Windows 向けのツールです。

## 起動

初回だけ、このフォルダで依存パッケージを入れます（[uv](https://docs.astral.sh/uv/) が必要）。

```bash
uv sync
```

あとは `videocut.bat` をダブルクリックします。動画ファイルを `videocut.bat` にドラッグ＆ドロップすると、その動画を開いた状態で起動します（`uv run videocut` でも起動できます）。

## 使い方

1. 「動画を開く…」か、ウィンドウへのドラッグ＆ドロップで動画を開く
2. 区間の始まりで **I**、終わりで **O** を押す（O を押したときに表示中のフレームも区間に含みます）。区間はいくつでも追加でき、タイムライン上で端をドラッグして調整できます
3. 「抜き出し」か「削除」、「無劣化・高速」か「正確」を選んで「書き出し…」

| 方式 | 速さ（この PC での実測） | 画質 | 切れ目 |
|---|---|---|---|
| 無劣化・高速 | ファイルのコピーとほぼ同じ。2時間15分・5.8GB の録画から削除して約17秒（D: ドライブへ）〜約55秒（C: ドライブへ） | 元のまま | キーフレーム単位（OBS の録画では約4.2秒間隔）。抜き出しは指定より少し広く残り、削除は指定より少し狭く消える |
| 正確（再エンコード） | 1080p60 で約 500 フレーム/秒（NVENC 使用）。残す部分 1 時間あたり約7分 | わずかに落ちる | 指定したフレームちょうど |

無劣化で実際に切る範囲は、区間一覧の右端の列と、タイムライン下の青い帯（書き出し後に残る部分）で確認できます。

## キー操作

| キー | 操作 |
|---|---|
| Space | 再生 / 一時停止 |
| ← / → | 1コマ戻る / 進む |
| Shift + ← / → | 1秒戻る / 進む |
| Ctrl + ← / → | 10秒戻る / 進む |
| ↑ / ↓ | 前 / 次のキーフレームへ |
| I / O | 開始点 / 終了点 |
| Esc | 開始点の取り消し |
| Del | 選択した区間を削除 |
| Home / End | 先頭 / 末尾へ |
| ホイール（タイムライン上） | 拡大・縮小（Shift + ホイールで左右に移動） |

## 補足

- 音声トラックが複数ある録画は、すべてのトラックを残して書き出します（プレビューで聞くトラックは右上で切り替え）
- 書き出し中は `元の名前.videocut-tmp.mp4` という一時ファイルに書き、完了したら指定した名前にします。中止すると一時ファイルは消えます
- テスト: `uv run pytest`
